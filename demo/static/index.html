零改造接入 2.9 知识库平台

本服务同时暴露 OpenAI 兼容接口。2.9 只需把模型提供方改成 openai、base_url 指向本服务， 检索、四维权限鉴权、SSE 流式与引用卡片全部保持原样。

2.9 系统配置

config
provider      = openai
base_url      = http://127.0.0.1:8802/v1
api_key       = any-string
model         = kb-finetuned-dph
temperature   = 0.2

# 然后重启 2.9：python run.py
# 问答工作台 → 设置 → 模型与系统参数 → 填入以上值

2.9 的鉴权仍在 Prompt 拼接前完成；微调模型只替换生成端，不能替代权限过滤。
